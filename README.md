# Yasas Wanigaarachchi — Engineering Portfolio

Personal engineering portfolio for **Yasas Nirmitha Wanigaarachchi** (`@YWanigaarachchi`) — Founder @ [SoftgenixLK](https://softgenix.lk), Full-Stack Software Engineer & Cloud Solutions Architect.

## Tech Stack

- **Framework**: React 19 + TypeScript (Strict Mode)
- **Build Tool**: Vite 6
- **Styling**: Tailwind CSS v4 (Dark/Light theme with persistent state)
- **Animations & Icons**: Framer Motion + Lucide React
- **Live Data**: GitHub REST API v3 with 15-minute `sessionStorage` caching and offline fallback

## Architecture

See [ARCHITECTURE.md](./ARCHITECTURE.md) for the complete system architecture, Mermaid diagrams, module layering, caching strategy, and deployment guide.

## Local Development

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Type-check & create production build
npm run build

# Preview production bundle locally
npm run preview
```
